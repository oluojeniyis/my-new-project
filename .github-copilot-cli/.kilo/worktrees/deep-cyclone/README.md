# TeesTale

TeesTale is a Next.js App Router storefront scaffold built with TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the local development URL printed by Next.js when the server starts.

## Phase 2 scope

- Home and shop pages with category filters and seeded sample product entries.
- Product detail pages with size, color, quantity, and custom design-note inputs.
- A browser-local cart and a non-submitting checkout layout.
- No authentication, database, email, payment, or other external integrations.

The sample product names, imagery, colors, and sizes are illustrative. Product prices and wholesale minimum quantities are intentionally unset because the source PRD did not provide confirmed catalog values. Replace the entries in `src/lib/products.ts` with the real catalog before taking orders.
